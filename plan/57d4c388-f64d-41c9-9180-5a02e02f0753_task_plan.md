# Task Plan: Add JSON output mode to filler clip CLI

## Scope and intent

Ticket: `57d4c388-f64d-41c9-9180-5a02e02f0753`

Goal: extend the filler CLI in `analyzer/filler.py` with a `--json` flag that emits one machine-readable JSON object containing:

- `start`
- `end`
- `length`
- `output`
- `seed`
- `requested_length`
- `avoided_intervals`

Constraints:

- Preserve the current human-readable stdout as the default behavior.
- Keep the change tightly scoped to the filler CLI and its tests.
- Do not change filler-selection or ffmpeg extraction behavior unless required by the CLI output contract.

## Files expected to change

- `analyzer/filler.py`
- `tests/test_filler.py`

No new test data or fixtures should be required. Existing unit-style CLI tests already monkeypatch extraction and capture stdout, which is sufficient for this ticket.

## Dependencies and sequencing

1. Confirm current CLI contract and test seam in `analyzer/filler.py` and `tests/test_filler.py`.
2. Add failing pytest coverage for JSON mode first.
3. Implement the minimum CLI-only code to make the new test pass.
4. Re-run the existing human-readable CLI test to confirm no regression.
5. Refactor only if needed to keep output formatting isolated and readable.
6. Run the targeted filler test module as final verification.

There are no graph dependencies, service dependencies, frontend dependencies, or docker-compose dependencies for this ticket.

## Risks to watch during implementation

- JSON field naming drift: use the ticket’s requested names exactly, especially `requested_length` and `avoided_intervals`.
- Avoided interval shape: keep the serialized form consistent with what the CLI parsed from `--avoid`, likely a JSON list of two-element numeric lists.
- Output contamination: in JSON mode, stdout should contain only the JSON object so agent workflows can parse it directly.
- Default behavior regression: do not replace or reformat the existing human-readable message when `--json` is absent.

- `analyzer/filler.py` accepts `--json`.

- `--json` prints one valid JSON object with the required fields.

- `pytest tests/test_filler.py` passes.
